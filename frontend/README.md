# NAV_TRACE dashboard (React)

Vite + React dashboard replaying a recorded agent run (`public/trace.json`,
generated by `demo/run_demo.py` at the repo root) — canvas render of the
level, a risk/reward telemetry chart with a synced playhead, playback
controls (play/pause, scrub, speed — also keyboard: space, ←/→), and a
module-status sidebar for the other 3 workstreams.

## Run it

```bash
npm install
npm run dev        # http://localhost:5173, hot reload
```

## Build for sharing / hosting

```bash
npm run build       # outputs to dist/
npm run preview      # serve the production build locally to sanity-check it
```

`dist/` is a static site — drop it on GitHub Pages, Vercel, Netlify, or any
static host. It fetches `trace.json` at runtime, so make sure that file
ships alongside `dist/index.html` (the build already copies everything in
`public/`).

## Updating the data

Regenerate `public/trace.json` from the repo root after changing the level
or the planner:

```bash
cd ..
PYTHONPATH=. python3 demo/run_demo.py
cp frontend/trace.json frontend-react-or-wherever/public/trace.json   # adjust path
```

(Or just point `demo/run_demo.py`'s output path at this `public/` folder
directly if you want one source of truth — that's a 1-line change in
`demo/run_demo.py`.)

## Structure

```
src/
  App.jsx                    orchestrates playback state, layout
  components/
    CanvasViewport.jsx       level render (canvas, imperative draw per frame)
    TelemetryChart.jsx       recharts risk/reward area chart + playhead
    ModulePanel.jsx          4-module status sidebar
    Ticker.jsx                bottom stats strip
```
